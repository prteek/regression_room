# Documenting plan

Use this document as a guideline to devise a high level analysis flow for a subsequent agent to either work on or to use as a guideline for verifying the work done on the post by user. Use appropriate information available in the context about analysis to make the analysis flow and contents tailored for each analysis

## Core elements to document

- An Introduction section that gives a general overview of the post and the associated problem setting, includeing the key questions the analysis will answer
- A Data section describing data sources and how data may guide the analysis based on experimental consideration or structure of the data itself e.g. clusters/nesting, domain knowledge about variables etc.
- Key assumptions framing the analysis
- Known constraints and scope boundaries
