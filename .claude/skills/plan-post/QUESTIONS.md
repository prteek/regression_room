# Post planning questions

Use these questions in the context of post to create a skeleton of analysis that can be used as a high level plan. You can ask them conversationally in one session or collect answers over time.

## Core questions

- Title: Post title which can be used to generate directories and files etc.
- Objectives: Problem statement for the post ? What is the analysis trying to accomplish ?
- Resources: Any existing resources on the topic
- Data:
    - Give some details about the data that will be used in this analysis. sources, variables, design that generated the data etc.
    - Is there a need to enrich with other datasets?
    - Does the analysis logic guide data manipulation/joins?
- Key Assumptions: What assumptions or constraints should frame the analysis?
- Scope: What is and is not included in this analysis ?
